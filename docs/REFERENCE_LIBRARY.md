# 资料库索引：开发前到哪里找依据

本索引对应仓库根目录的 `资料文件/`。它帮助接手工程车、炮台车的成员和 agent 找到原始资料，并区分“资料写了什么”“项目已经实现什么”“实车核验了什么”。资料库是参考输入，不参与两车固件编译；资料中的示例工程、旧设计和厂商默认值不能直接当作本车接线或控制参数。

修改代码前先读[项目需求](PROJECT_REQUIREMENTS.md)、对应车辆及模块 README；涉及下表的协议、器件、规则或机构时，再打开相应原始资料核对。若资料与用户明确需求、当前工程配置或实物测量不一致，记录冲突并保留待确认状态，不自行覆盖。

## 资料库中的几个易混淆点

- `资料文件/陀螺仪移植文件/` 是**参考工程**，其中的 `Drivers/`、`Middlewares/`、`MDK-ARM/`、`.ioc` 和编译产物不属于当前两车固件源码；当前实现应在各自 `project file/` 内查找。
- `资料文件/2组期中考核/` 保存两车装配及阶段文档，不能替代本车最新的电机映射表和实测参数。
- 规则手册提到的裁判系统“主控模块”与两辆车各自的 C 板是不同设备；0x31 功率帧的**协议定义**、**接线来源**和**已上板验证**是三件事。[规则摘录](RULES_REQUIREMENTS.md)记录了已知值与疑点。
- 资料库目前没有可直接确认本车 CAN1/CAN2 设备分配、全部电机 ID、实车安装方向、机构零位/限位、IMU 加热器参数的最终接线/标定表。相关配置继续保持待确认；拿到经核验的数据后，先更新[硬件拓扑](HARDWARE_TOPOLOGY.md)和对应车辆配置。

本索引按文件目录、资料标题和已有项目文档建立；它不表示已逐页复核每份厂商手册，也不表示资料中的示例已在实车验证。新增或替换资料时，同步更新本表的入口、版本与核验状态。
