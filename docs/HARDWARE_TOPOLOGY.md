## 接线原则

- 两车各一块 C 板，各自独立供电和控制；公共逻辑分别保存并同步维护。
- 底盘动力与机身/上层供电按规则分开，具体端口以最终接线图为准。
- 裁判系统主控模块单独列出，不等同于第二块 C 板。
- 任何未确认的 CAN 总线、ID、方向、减速比、零位、限位和 PID 继续保持未配置。
