# Motor_Driver 电机驱动

## 已实现

- `DJI_motor` 支持 M3508、M2006、GM6020 的反馈解析、速度/位置 PID 和组合帧发送。
- 生命周期：`WAIT_FEEDBACK → READY`，无反馈超时进入 `FAULT`；构造不等待、不自动使能。
- `DJI_MOTOR_ENABLE_OUTPUT` 只在反馈就绪后允许发送；`DJI_MOTOR_DISABLE_OUTPUT` 清零并关闭输出。
- 发送使用独立载荷副本，不持有外部缓冲区指针。

## 未实现 / 边界

- 达妙 4310/6006 没有适配，不能用 DJI 协议代替。
- `app_motor` 到本驱动的硬件适配层尚未接入；当前没有实例化电机，未发送运动报文。
- 组合帧槽位、ID、方向、减速比、零位、限位和 PID 仍需实车确认。
- 上板前必须验证 CAN 反馈、组合帧冲突、失能/制动行为和超时恢复。
